# OpenGL 실습 솔루션

모든 실습이 `Config`의 CMake 설정과 GLFW, GLEW, GLM 설치를 함께 사용합니다.

```text
OpenGL
├─ OpenGL.slnx
├─ Config
│  ├─ CMakeLists.txt
│  ├─ CMakePresets.json
│  ├─ vcpkg.json
│  ├─ .gitignore
│  └─ README.md
├─ out
└─ Project1
   ├─ Project1-1.cpp
   ├─ Project1-2.cpp
   ├─ Project1-3.cpp
   ├─ Project1-4.cpp
   ├─ Project1-5.cpp
   ├─ Project1-6.cpp
   ├─ Project1-7.cpp
   ├─ Project1-8.cpp
   ├─ Project1-9.cpp
   ├─ Project1-10.cpp
   └─ Project1-11.cpp
```

## Visual Studio에서 실행

1. `OpenGL.slnx`를 엽니다.
2. 실행할 실습 프로젝트를 시작 프로젝트로 지정합니다.
3. `F5` 또는 `Ctrl+F5`를 누릅니다.

## 명령줄에서 구성 및 빌드

Visual Studio의 Developer PowerShell에서 `OpenGL/Config` 폴더로 이동한 후 실행합니다.

```powershell
cmake --preset windows-x64
cmake --build --preset debug
```

## Project1-7 추가

1. `Project1/Project1-7.cpp`를 만듭니다. Visual Studio의 **새 프로젝트**는 선택하지 않습니다.
2. `Config/CMakeLists.txt` 마지막에 다음 줄을 추가합니다.

```cmake
add_opengl_example(Project1-7 ../Project1/Project1-7.cpp Project1)
```

3. `Config` 폴더에서 `cmake --preset windows-x64`를 실행합니다.
4. `OpenGL.slnx`에서 **추가 > 기존 프로젝트**를 선택합니다.
5. 반드시 CMake가 생성한 `out/build/windows-x64/Project1-7.vcxproj`를 추가합니다.

`Project1` 폴더에는 CPP 소스만 두며, Visual Studio가 별도로 생성한 `.vcxproj`는 사용하지 않습니다.

빌드 결과와 공용 라이브러리는 모두 루트 `out`에 저장됩니다.

## GLSL 실습 7~11

7~11번 실습은 OpenGL 3.3 Core Profile, GLSL 셰이더, VAO/VBO를 사용합니다. 셰이더 코드는 각 CPP 안에 있어 별도의 셰이더 파일 경로 설정은 필요하지 않습니다.

| 실습 | 시작 프로젝트 | 조작 |
| --- | --- | --- |
| 7 | `Project1-7` | `P/E/T/R`: 점/선/삼각형/사각형 생성, 왼쪽 클릭: 선택, `W/A/S/D`: 상/좌/하/우, `I/J/K/L`: 좌상/우상/좌하/우하, `1/2/3/4`: 모두 좌/우/상/하 이동, `C`: 모두 삭제 |
| 8 | `Project1-8` | 왼쪽 클릭: 해당 사분면의 삼각형 교체, 오른쪽 클릭: 크기를 한 단계 조절(상한/하한에서 증감 방향 전환), `A/B`: 면/선, `C`: 네 삼각형 다시 생성 |
| 9 | `Project1-9` | 8번의 마우스·키보드 조작에 더해 `1`: 튕기기, `2`: 좌우 지그재그, `3`: 상하 뾰족 지그재그, `4`: 부드러운 스파이럴 |
| 10 | `Project1-10` | 왼쪽 드래그: 같은 크기·방향의 조각을 모양판에 맞추기, `R`: 리셋 |
| 11 | `Project1-11` | `Space`: 지그재그 이동 시작/일시정지, `R`: 보드 리셋 |

`Q` 또는 `Esc`로 종료합니다. 9번은 `1`~`4`를 누르면 삼각형 네 개가 서로 다른 속도로 각자의 사분면 안에서 움직이고, 같은 숫자를 다시 누르면 멈춥니다. `4`는 각도를 조금씩 바꾸고 반지름을 계속 늘려 부드러운 스파이럴로 이동합니다. 한 바퀴마다 반지름이 약 0.1씩 커집니다. 벽에 닿는 순간 해당 사분면의 정중앙으로 순간이동해 원 이동을 다시 시작합니다. 왼쪽 클릭으로 해당 사분면에서 생성한 삼각형을 교체합니다. 모든 이동 방식에서 삼각형의 꼭짓점이 진행 방향을 향하도록 회전합니다. 1~3번은 다음 방향 전환 지점까지의 경로를 흰색 선으로 표시합니다. 4번은 벽에 닿기 전까지의 전체 스파이럴 경로를 흰색 선으로 미리 보여 줍니다. 중앙으로 순간이동하거나 삼각형을 교체하거나 크기를 바꾸면 경로를 다시 계산합니다.

10번은 사각형·바람개비·직사각형과 추가한 집·계단의 총 5개 모양판입니다. 집은 큰 사각 조각, 계단은 작은 사각 조각으로 크기가 구분됩니다. 맞는 칸 가까이에 놓으면 정확한 위치에 붙으며, 모양판의 모든 칸이 채워지면 해당 조각들이 고정됩니다. 맞지 않는 곳에 놓으면 드래그를 시작한 자리로 돌아갑니다. 필요한 조각은 모두 제공하고 여분의 개수와 시작 위치를 랜덤하게 정합니다. 계단은 작은 사각형 3개로 만듭니다.

11번은 실행 시 콘솔에서 행(세로)과 열(가로)을 입력합니다. 예를 들어 `5 8`은 세로 5줄, 가로 8칸입니다. 입력한 크기에 맞춰 칸 크기를 조절하고, 전체 칸의 약 35~50%에 장애물을 배치합니다. 왼쪽 위에서 시작해 0.2초마다 지그재그로 한 칸씩 이동하며, 마지막 행의 끝에서 멈춥니다. 행 개수가 짝수면 왼쪽 아래, 홀수면 오른쪽 아래가 도착점이며, `1 1`은 시작과 동시에 완료 상태입니다. `R`은 같은 크기로 보드를 다시 만듭니다. 충돌 시 주인공과 장애물의 모양을 서로 교환하고 해당 칸을 0.45초 동안 주황색으로 표시합니다. 색상과 크기는 각 도형의 기존 값을 유지합니다.
